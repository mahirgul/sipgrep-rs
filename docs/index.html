Why Engineers Choose sipgrep-rs

Engineered from clean RFC specifications with zero legacy dependencies

100% Clean-Room RFC 3261

Written from pure IETF RFC 3261, RFC 3262, and RFC 4566 (SDP) specs without using or copying sngrep source code. Safe for commercial use under the MIT license.

Real-Time Ladder Diagrams

Automatic call session correlation by Call-ID. Visualizes endpoint interactions, directional arrows, provisional status codes, and call states in ratatui TUI.

Blazing Fast Pure Rust

Powered by Rust 2024, etherparse for zero-copy packet slicing, and crossbeam channels. Ultra-low CPU usage even under high VoIP traffic.

Interactive Search & Filter

Filter calls on the fly by pressing /. Matches Call-ID, Caller URI, Callee URI, IP addresses, and methods.

CI & Script Friendly

Pipe ASCII ladder diagrams straight into logs or automation scripts using --ladder or stream packets directly to stdout with --dump.

PCAP & Live Sniffing

Supports live interface sniffing (eth0, any, loopback) as well as offline analysis of recorded Wireshark .pcap / .pcapng captures.

Getting Started

Get up and running with sipgrep-rs in seconds

1. Install system prerequisites (libpcap-dev):
sudo apt-get install -y libpcap-dev build-essential
2. Clone & build release binary:
git clone https://github.com/mahirgul/sipgrep-rs.git && cd sipgrep-rs && cargo build --release
3. Start live packet sniffing:
sudo ./target/release/sipgrep-rs -i eth0
